# Animation, object lists and creature AI (a) (w9-animation-object-a)

Branch `agents/w9-animation-object-a`. New source is under `experimental/sources/w9-animation-object-a-*`; shared helpers are in `w9-animation-object-a-common`. Reference executable: the private `SLUS_205.65` named in the docs, read locally only. No game bytes, listings or decompiler output are committed; addresses and extents are that file's symbol table.

Every function compiles with the reviewed `authored_cpp` profile and has a `host_check.cpp` (host compiler, exits non-zero on a wrong store, result or branch; not a plan input). Each was also run against the original on a private R5900 interpreter harness kept outside git: original and authored function ran from identical memory snapshots and the return value, call log and every changed byte outside the stack were compared. That harness run is not part of the repository and no byte match of compiled code is claimed.

## What was checked

- Every function: its `host_check.cpp` compiles with `c++ -std=c++17 -Wall` (float code with `-ffp-contract=off`) and exits zero. Host checks mock the callees and assert stores, call order, boundaries and bit tests; the larger ones (`genericMove`, `animMapAnimationSounds`, `getSmartRandomDestination`, `gameLineUpdatePosition`) were mutation-spot-checked, and surviving mutants were closed with extra cases (for example the strict landing test and the 0.001 margin in `genericMove`, the last-versus-highest platform in `genericMove`).
- Every function: a private paired run. A small R5900 interpreter (outside git; MIPS III, COP1 single float, `rsqrt.s`/`sqrt.s` added for this package) loaded the private image, linked the authored object next to it with every undefined symbol bound to the original's address, and ran the original and the authored function from identical memory snapshots with the same Python stand-ins for callees. Return value (where the function returns one), the callee call log with arguments, and every changed byte outside the stack were compared. ## Conventions used

- Importer-facing names are the mangled originals, written as `extern "C"` definitions. Records are addressed by byte offset through `w9-animation-object-a-common/mem.hpp` (a copy of the level-and-animation-load helper; host checks define `NORRATH_HOST_ARENA` and supply a 32-bit address map). No class declaration is claimed.
- Callees outside this package are left as imports under their original names, except where an authored provider already exists, in which case the provider is called: `norrath_factory_strlen`, `norrath_factory_strncmp`, `norrath_factory_atoi`, `norrath_factory_ctype_minimum_view`, `norrath_player_atof` and `norrath_player_double_to_float`.
- Struct returns: `getSmartRandomDestination__8Creaturei` is written with the explicit result pointer as first argument and returns it, because the reviewed compiler returns a 12-byte struct in registers while the original passes a hidden pointer. Importers already declare it that way.
- Float constants whose image value is not the nearest float to the decimal (1/60 as 0x3c888888, 0.001 as 0x3a83126e, 9.0 less one unit as 0x410fffff) are written by bit pattern in `genericMove`; for 1/60 the reviewed compiler folds `1.0f / 60.0f` to the same 0x3c888888, which was checked in the emitted assembly for `animGlobalSync` and `animAddOneShot`.

## Observed, inferred, unknown (short form; each source header has the full text)

- Observed: animation state header byte 4 is a signed component count and byte 5 the capacity; components are 32 bytes from state+8 (header pointer +0, link pointer +4, floats +8..+20, float +24, flag halfword +28). `animAdd*` fill these slots; `animFindComponentWithFlags` returns -1000000000 for no match; `animGlobalSync` wraps one global frame time per component with `fmodf`. The line path state is cleared over 56 bytes; `gameLineUpdatePosition` walks 64-byte point records of a line (count at +4, records at +20) using a plane distance per point. `genericMove` scales the move by 1/60, moves with world collision when the squared length exceeds 0.001, re-links the grid cell node, collides with objects found in a box and finishes with gravity (9.0) and a floor test.
- Inferred: the +36 count and +44 float of the path state are a signed lap count and a path fraction; the `genericMove` bits 1, 2 and 4 are hit, pushed and landed; object flag 0x10 selects platform handling.
- Unknown: see the final section.

## Authored but never executed

Nothing here has run on the EE or in the game. Everything was run only on the private interpreter against the original image and on the host with mocks. In particular: `gameLineUpdatePosition` and `genericMove` call `distanceToPlane`, `initPosition`, `gameLineGetNextPoint`, `iatan2`, `objectMoveWithWorldCollision` and the collision slot only as stand-ins (their authored or original bodies were not run inside the comparison); `animGlobalSync` and `convertPointersToIndicies` called stand-ins for `fmodf`, `updateAnimation` and `pack`; the data units have never been initialised or used. The interpreter has no floating-point exception model, no unaligned-access trapping, and divides without the zero-division trap the reviewed compiler adds (`gameLineUpdatePosition` divides by the line's point count; a zero count would trap on the authored build and silently continue in the original).

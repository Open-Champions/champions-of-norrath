# w9-startup-crt-d

Startup and runtime support (d). Sources are under `experimental/sources/w9-startup-crt-d-*`. Each unit compiled alone with the plan's `authored_cpp` flags; host checks (`host_test.cpp`) include host headers and stay out of the EE plan. Addresses are from the private executable whose SHA-256 is the snapshot `target_sha256`. Compiled sizes are `st_size` from the EE compile, not original-byte matches. Nothing was executed on the EE or in game.

## Per-function notes

- `free` (`0x003015a0`, 72 bytes; compiled 64). Observed: lock service, `_free_r` (`0x00300608`) with the pointer re-read, unlock service as a tail call; each `_impure_ptr` read is a fresh load. Callee for `_free_r` is the authored `norrath_player_free_reentrant`. Host check covers order, re-reads and the null pointer reaching `_free_r`.
- `memalign` (`0x00301318`, 100 bytes; compiled 88). Observed: lock, `_memalign_r` (`0x00301380`) with the pointer re-read, then (alignment, size), unlock; returns the `_memalign_r` result. `_memalign_r` is not authored and is a newly opened import.
- `memmove` (`0x003020ac`, 260 bytes; compiled 132). Observed: backward byte copy only when source < destination < source + count (unsigned), otherwise forward; returns the destination. The original's quadword and doubleword fast paths are not reproduced; only byte results are. Host check sweeps all overlap offsets and counts 0..40 against a temp-buffer model.
- `blockFree__FPv` (`0x001447d8`, 84 bytes; compiled 128). Observed: the row is the last one whose start word (offset 8 of the 16-byte row, tested from row 1) is at or below the pointer; the object is pushed onto the list head at row offset 12. That is the existing `norrath_block_free`, so the original name is added as a second global symbol on the same extent (same method as `memAlloc__FiPc`). This edits `experimental/sources/block-allocator-lifecycle-build/block_free.cpp`: its plan file hash must be regenerated. `check_same_extent` against the EE object reports one shared extent of 128 bytes.
- `amx_FindPublic` (`0x00135bb8`, 268 bytes; compiled 268). Observed: binary search over the header's public records (count: signed halfword at header+32; record table offset: word at header+36; 24-byte records, name from +4), strcpy to a 32-byte local then strcmp against the wanted name; found stores the index and returns 0, not found stores `0x7fffffff` and returns 19. Header and count are re-read each iteration. Host check compares against a linear model over empty, one, two, 37 and 38-entry tables, with hits and misses. Unknown: whether 19 has a name, and the rest of the machine object. Opens `strcpy`, `strcmp` (already provided by other packages).
- `kputchar` (`0x002d6778`, 60 bytes, local symbol; compiled 36). Observed: poll the word at `0x1000f130` until bit `0x8000` is clear (fresh read each pass), store the low byte at `0x1000f180`, return the argument. Inferred (not shown by the code): a serial transmit status/data pair, since `serialPutchar` feeds it. Host check scripts the status register and data register through two macros. The original body has padding between the poll and the store that the compiled body lacks.
- `kputs` (`0x002dfa68`, 36 bytes; compiled 36). Observed: one-word local holding the text pointer, `Deci2Call(16, &local)`; the result register is untouched after the call, so the `Deci2Call` result is what returns (callers ignore it). Unknown: what service 16 does. Opens `Deci2Call`.
- `new_iob` (`0x002d89f8`, 136 bytes, local; compiled 160). Observed: `_sceFsIobSemaMK`, `WaitSema(_fs_iob_semid)`, first slot of the thirty-two 16-byte `_iob` slots with a zero word at +4 gets `0x10000000` there, `SignalSema` (id re-read), return the slot, or 0 with none free. Unknown: meaning of `0x10000000`; what `_sceFsIobSemaMK` does. Opens `_sceFsIobSemaMK` (local routine at `0x002d8998`, 92 bytes) and reuses `_iob`, `_fs_iob_semid` from the libfs-state unit.
- `get_iob` (`0x002d8a80`, 108 bytes, local; compiled 128). Observed: same prologue; an index of 32 or more (unsigned) returns 0, otherwise `_iob + index * 16`; semaphore signalled either way. Slot contents are not examined.
- `gsm_create` (`0x002eb790`, 76 bytes; compiled 68). Observed: `__wrap_malloc(2568)`; null returns null; otherwise `memset(p, 0, 2568)`, the 64-bit word at +2472 set to 40, return the block. Inferred only: this looks like the public GSM 06.10 codec state; the image has no field names. Host check verifies every byte of the cleared object and that nothing is written past it.
- `gsm_option` (`0x002edab8`, 44 bytes; compiled 44). Observed: only option 3 acts, anything else returns -1 and touches nothing; option 3 returns the low 32 bits of the 64-bit word at +2464 and, when the pointer is non-null, stores the pointed-at int sign-extended into that word. Inferred only: matches the public library's option of that number.

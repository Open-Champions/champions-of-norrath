# w15-vi-particle-a

Package: particle emitter, effect volume, light and point sprite (1 of 2). Branch `agents/w15-vi-particle-a`. Source is under `experimental/sources/w15-vi-particle-a-*`, one directory per function; each holds the authored `.cpp` (observed / inferred / unknown in its header comment) and a `host_check.cpp` that is not a build input.

## How each function was checked

- Compiled with the reviewed `authored_cpp` flags and the reviewed EE g++ (each unit separately; no full partial build was run).
- Compared against the original function with a private R5900 interpreter harness (outside git): the same memory snapshot and the same stub callees feed the original and the authored object, and the call logs plus every changed byte outside the stack must match. Scenario counts and mutation checks are in each commit message. Hand-made mutations of the authored source (changed constants, operand order, conditions, indices) were caught by the paired runs.
- A native host check per unit, built with `-Wall -Wextra -Werror`.
- `python3 -m unittest discover -s tools -p 'test_*.py'` was run on the branch before the final push: 214 tests, all passed.

# Champions of Norrath work

Read README.md, CONTRIBUTING.md and targets/README.md before changing this target.
This repository has no established baseline or reconstruction verifier yet. Do not
borrow Return to Arms' hash, entry addresses, function count or match percentage.

- Inspect Git status and current work ownership first; preserve other contributors' files.
- Establish the exact private executable and version before extracting a function inventory.
- Keep game binaries, disc images, assets, proprietary tools and generated decompiler output private.
- Write findings in your own words with addresses tied to the verified target.
- Track observed, inferred and unknown separately. Avoid guessed names and compatibility claims.
- Coordinate in an issue before a large area; use bounded, explicitly owned agent tasks.
- Reuse the shared verification design once this target is established; do not maintain an
  unreviewed copy of Return to Arms' verifier with only the game name changed.
- Publish only independently authored source and sanitized evidence. One verified complete
  function per reconstruction commit; no credit for assembly dumps or placeholders.
- Native Godot work belongs in Open-Champions/open-champions-godot. Existing Return to Arms
  research stays in Open-Champions/champions-return-to-arms-re.
- Report exact checks performed and remaining blockers. No source or runtime progress is
  implied by creating this repository.
